## 1. Onboarding `/start`

- [x] Шаг 1 — приветствие
- [x] Шаг 2 — часовой пояс (пресеты UTC+2/3/5/6 + произвольный ввод, валидация -12..+14)
- [x] Шаг 3 — время брифа (пресеты 07/08/09/10 + произвольный ввод HH:MM)
- [x] Шаг 3 — проверка что время брифа не в тихих часах (пресеты и ручной ввод)
- [x] Шаг 4 — тихие часы (пресеты + настройка от/до + пропустить, поддержка переноса через полночь)
- [x] Шаг 5 — завершение с итоговым экраном и главным меню
- [x] Повторный `/start` → главное меню без онбординга
- [x] Незавершённый онбординг при следующем сообщении → продолжает с места остановки (resumeOnboarding в /start и message:text)
- [x] `isEditing` флаг — после редактирования возвращает в `/settings`

## 3. Capture `/add`

- [x] FSM: title → category → duration → options → [date / time+date / delegate] → done
- [x] Валидация title (пустое, длиннее 200)
- [x] Валидация date (формат DD.MM / DD.MM.YYYY, дата в прошлом)
- [x] Валидация time (формат HH:MM)
- [x] Предупреждение о тихих часах при вводе `due_time`
- [x] Делегирование: `delegated_at = now()`, `remind_delegation_at = +3 дня`
- [x] Опции убираются из меню после заполнения
- [x] Back-навигация через `sceneHistory` стек
- [x] Подтверждение с заполненными тегами + "Добавить ещё" / "Открыть инбокс"
- [x] `/add` в середине другого FSM-флоу должен сбрасывать текущий флоу
- [x] Таймаут 30 минут — сессия сбрасывается при следующем действии после истечения

## 5. Notifications (job)

- [x] Тип 1 — Делегирование: через 3 дня, кнопки: выполнено / snooze +3 дня / забрать себе
- [x] Тип 2 — Дедлайн по дате (без времени): утром в день дедлайна, кнопки: выполнено / перенести / удалить
- [x] Тип 3 — Дедлайн по времени: за час до `due_time`, кнопки: выполнено / удалить; всегда отправляется в тихие часы
- [x] Тип 3 — утреннее напоминание: утром в день дедлайна для задач с `due_time`, текст "Сегодня в HH:MM", кнопки: выполнено / перенести / удалить
- [x] Перенос: пресеты (завтра, через 3 дня, следующая неделя) + произвольная дата
- [x] Тихие часы: типы 1 и 2 уважают quiet_hours, тип 3 — всегда отправляет
- [x] `last_activity_at` обновляется при изменении статуса через уведомление

## 6. Утренний бриф (job — каждую минуту, per-user timezone)

- [x] Определение кому пора (timezone + morning_brief_time + last_brief_sent_at)
- [x] Проверка тихих часов перед отправкой
- [x] Защита от двойной отправки (`last_brief_sent_at`)
- [x] Блок 1: сколько времени (пресеты + произвольный ввод)
- [x] Блок 2: обязательные задачи CAREER с `due_date = сегодня`, вычет из бюджета
- [x] Перегрузка: обязательные > бюджет → предупреждение и завершение
- [x] Блок 3: подбор кандидатов по одному (CAREER по ELO → PERSONAL по ELO), "Добавить" / "Пропустить" / "Готово"
- [x] Блок 4: итоговый план (обязательные + дополнительные + итог часов)
- [x] Блок ELO: 10 пар из активных задач без дедлайна (только если 2+ задач)
- [x] Таймаут 2 часа — сессия сбрасывается при следующем действии после истечения

---

## 7. Субботний бриф (job — суббота 20:00)

- [x] Определение типа брифа (обычный / месячный / квартальный)
- [x] Блок архива (квартальный): показ задач → удаление из БД после отправки
- [x] Блок холодильника (месячный/квартальный): "Вернуть" → ACTIVE / "Удалить" → DELETED / нет ответа → ARCHIVED
- [x] Блок статистики (всегда): thisWeek / динамика / среднее / активных; адаптивно по неделям использования
- [x] Блок задач без движения (7+ дней): "Оставить" / "Выполнено" / "Удалить" / нет ответа → FROZEN
- [x] Автозамораживание стейл-задач и архивирование замороженных после отправки брифа
- [x] Блок ELO: 30 пар из активных задач без дедлайна (только если 2+ задач)

## 9. Жизненный цикл (`last_activity_at`)

- [x] ACTIVE → FROZEN: через субботний бриф (7+ дней без активности)
- [x] FROZEN → ARCHIVED: через субботний бриф (нет ответа на блок холодильника)
- [x] ARCHIVED → DELETE из БД: квартальный субботний бриф
- [x] "Оставить" в субботнем брифе → `last_activity_at = now()`
- [x] Выполнение задачи (инбокс) → `last_activity_at = now()`
- [x] Удаление задачи вручную через инбокс → `status = DELETED`
- [x] Выполнение/удаление через уведомления → `last_activity_at = now()`
